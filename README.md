## 👩‍💻 About Me

I'm a **Software Engineering graduate from FAST-NUCES** focused on two closely connected areas:

**Artificial Intelligence Engineering** and **Software Quality Assurance**.

On the AI side, I work with **Machine Learning, NLP, RAG, embeddings, semantic retrieval, reranking, LLM APIs and AI-powered applications**.

On the QA side, I work with **manual testing, API testing, database validation, automation testing, regression testing and defect management** using tools such as **Playwright, Selenium, Postman, Jira, JUnit and TestNG**.

What interests me most is the intersection between the two:

> **Building intelligent software and making sure it behaves reliably in the real world.**

I also use **n8n** for workflow automation, API integrations and trigger-based processes.
